Install in about a minute

It isn't on the Chrome Web Store yet, so you load it yourself. No build step.

  1. Download the zip

    Get better-edurec-<version>.zip from the latest release and unzip it somewhere you'll keep it.

  2. Open Chrome's extensions page

    Go to chrome://extensions and switch on Developer mode in the top right.

  3. Load unpacked

    Click Load unpacked and choose the unzipped folder, the one with manifest.json in it.

  4. Open EduRec

    Sign in as usual. The Overview's checklist walks you to the pages it reads, once each.

Or straight from the repo

Clone it, then do steps 2 and 3 with the cloned folder.

git clone https://github.com/anselmlong/better-edurec.git
cd better-edurec
# optional: run the tests
npm test

To update, replace the folder (or git pull) and click the reload icon on the extension's card in chrome://extensions.

On real EduRec
