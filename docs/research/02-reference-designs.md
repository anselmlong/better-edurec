# Comparable designs & what to steal

| Reference | What it is | Steal |
|---|---|---|
| **NUSMods** (nusmods.com) | Student-built NUS module planner / timetable | Week-grid timetable, module chips with colour per course, exam clash view, keyboard-first search. It's the de-facto EduRec companion — students already trust its visual language. |
| **Workday Student – Academic Progress** | Degree audit in a modern SIS | Summary strip (major, cum. GPA, % satisfied) → requirement rows with Satisfied / In progress / Not satisfied → drill into eligible courses. Caveat: UBC dropped the progress *wheel* because % misled ([Ubyssey](https://ubyssey.ca/news/workday-academic-progress-wheel/)) — keep units-based bars + detail table. |
| **TU Graz study progress dashboard** | Research dashboard for degree structure | Visual degree structure, curriculum-aware analytics. |
| **Texas Law "Status Page"** ([case study](https://law.utexas.edu/ux-case-studies/dashboard/)) | Personalised student dashboard | One status page from admission → graduation; surface what's relevant to the current stage. |
| **HKUST Student Center redesign** ([project](https://emia2200.hkust.edu.hk/node/184)) | Student redesign of a PeopleSoft portal (same platform as EduRec) | Validates the critique: nested nav + no contextual hierarchy are the core problems. |
| **Linear / Stripe Dashboard** | Best-in-class operate UIs | ⌘K command palette, dense-but-calm tables, status pills, crisp empty states. |
| **Apple Wallet / boarding passes** | Ticket-style cards | Exam "tickets" with seat, venue, countdown. |
| **Monzo / Revolut** | Money timeline | Scholarship disbursements & bills as a transaction feed. |
| **MedPath concept** ([contra](https://contra.com/p/AUeesZoL-med-path-student-medical-portal-uxui-design)) | Student portal | Direct "appeal" action next to a grade. |
